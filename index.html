iMirly - Plataforma de Marketplace de Servicios

Conecta proveedores de servicios con clientes mediante chat en tiempo real, presupuestos inteligentes, pagos seguros y valoraciones mutuas

Bienvenido a iMirly

Una plataforma moderna de marketplace de servicios que conecta proveedores con clientes a través de comunicación en tiempo real, negociación inteligente de presupuestos y procesamiento seguro de pagos.

Comenzar Ver Arquitectura

Características Principales

iMirly proporciona un ecosistema completo para operaciones de marketplace de servicios con funcionalidad de extremo a extremo.

Chat en Tiempo Real

Mensajería dinámica con burbujas de presupuesto integradas directamente en las conversaciones

Presupuestos Inteligentes

Sistema inteligente de negociación de presupuestos con ofertas, rechazos y aprobaciones

Billetera Virtual

Retención segura de fondos con gestión automática de comisiones y flujos de pago

Gestión de Tareas

Seguimiento dinámico de tareas con estados de completado por el proveedor y aprobación por el cliente

Sistema de Valoraciones

Reseñas bidireccionales de 5 estrellas que alimentan un algoritmo de confianza

Autenticación Segura

Autenticación basada en JWT con Spring Security y encriptación BCrypt

Componentes de la Plataforma

iMirly está construido como una plataforma full-stack con cliente Android nativo y API backend robusta.

App Android

Aplicación Android nativa construida con Kotlin y Jetpack Compose

API Backend

API REST Spring Boot con arquitectura hexagonal y PostgreSQL

Stack Tecnológico

Frontend Android

  • Lenguaje: Kotlin con UI 100% declarativa
  • Framework UI: Jetpack Compose
  • Redes: Retrofit + OkHttp con interceptores JWT
  • Gestión de Estado: ViewModels y Coroutines
  • Navegación: Compose Navigation

Backend API

  • Framework: Java 21 + Spring Boot 4
  • Arquitectura: Arquitectura Hexagonal / Limpia
  • Base de Datos: PostgreSQL con Spring Data JPA
  • Seguridad: Spring Security con tokens JWT
  • Estilo API: RESTful con métodos HTTP convencionales
