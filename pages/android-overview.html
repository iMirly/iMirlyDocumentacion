Visión General de la App Android

Guía completa de la arquitectura y características de la aplicación iMirly para Android, construida con Jetpack Compose y las mejores prácticas modernas de desarrollo.

Introducción

La aplicación iMirly para Android está construida con Jetpack Compose y sigue las mejores prácticas modernas de desarrollo Android utilizando la arquitectura MVVM. La app conecta usuarios con profesionales de servicios locales a través de una plataforma de marketplace segura y en tiempo real.

Sistema de Autenticación

Autenticación JWT segura con inyección automática de tokens

kotlin 
package com.imirly.app.network

import okhttp3.Interceptor
import okhttp3.OkHttpClient
import retrofit2.Retrofit
import retrofit2.converter.gson.GsonConverterFactory

object RetrofitClient {
    private const val BASE_URL = "http://10.0.2.2:8080"

    private val okHttpClient = OkHttpClient.Builder()
        .addInterceptor(Interceptor { chain ->
            val originalRequest = chain.request()
            val token = TokenManager.jwtToken

            val newRequest = if (token != null) {
                originalRequest.newBuilder()
                    .header("Authorization", "Bearer $token")
                    .build()
            } else {
                originalRequest
            }

            chain.proceed(newRequest)
        })
        .build()
}

Flujo de Navegación

La app utiliza Jetpack Navigation con la siguiente estructura de rutas:

kotlin 
NavHost(navController = navController, startDestination = "onboarding") {
    composable("onboarding") { OnboardingScreen(navController) }
    composable("login") { LoginScreen(navController) }
    composable("register") { RegisterScreen(navController) }
    composable("main") { MainScreen(navController) }
    composable("mis_anuncios") { MisAnunciosScreen(navController) }
    composable("change_password") { ChangePasswordScreen(navController) }
    composable("saldo_screen") { SaldoScreen(navController) }
    // Rutas adicionales...
}

Nota de Implementación: La app utiliza navegación popUpTo para prevenir que los usuarios vuelvan a las pantallas de login después de la autenticación.
