Bienvenido a iMirly

iMirly es una plataforma integral de marketplace de servicios que reúne a proveedores de servicios y clientes en un ecosistema fluido, seguro y eficiente. Construida con arquitectura moderna y tecnologías de vanguardia, iMirly agiliza todo el ciclo de vida de la contratación de servicios, desde el descubrimiento hasta la finalización.

¿Qué es iMirly?

iMirly es una aplicación de doble plataforma que consta de:

App Móvil Android

Aplicación Android nativa construida con Jetpack Compose para una experiencia de usuario moderna e intuitiva

Backend Spring Boot

API REST robusta impulsada por Java 21 y Spring Boot 4, siguiendo principios de arquitectura hexagonal

Características Principales

Comunicación por Chat en Tiempo Real

Conecta proveedores de servicios y clientes a través de un sistema de mensajería integrado que soporta:

  • Mensajes de texto entre las partes
  • Burbujas de propuesta de presupuesto dentro de las conversaciones
  • Notificaciones de estado del contrato
  • Confirmaciones de lectura y seguimiento de mensajes

Sistema de Presupuestos Inteligente

Flujo de trabajo de propuestas optimizado integrado directamente en el chat:

1

Solicitud de Servicio

El cliente inicia una solicitud de servicio vinculada a un anuncio del proveedor

2

Propuesta de Precio

El proveedor revisa los detalles y propone un precio dentro del chat

3

Aprobación del Cliente

El cliente revisa y acepta/rechaza la propuesta

4

Pago en Garantía

Los fondos se retienen de forma segura tras la aceptación

Integración de Billetera Virtual

Gestión segura de pagos con un sistema de billetera integrado:

  • Los clientes pagan por adelantado al aceptar presupuestos
  • Los fondos se retienen en garantía hasta la finalización del servicio
  • Los proveedores reciben el pago tras la aprobación del cliente
  • Seguimiento completo del historial de transacciones
domain/model/User.java 
public void restarSaldo(Double cantidad) {
    if (cantidad == null || cantidad <= 0) {
        throw new IllegalArgumentException("La cantidad debe ser mayor que cero.");
    }
    this.saldo -= cantidad;
}

public void sumarSaldo(Double cantidad) {
    if (cantidad == null || cantidad <= 0) {
        throw new IllegalArgumentException("La cantidad debe ser mayor que cero.");
    }
    this.saldo += cantidad;
}

Gestión Dinámica de Tareas

Los proveedores gestionan la entrega del servicio mediante seguimiento de estado:

  • Marcar el trabajo como "Completado" cuando finalice
  • El cliente revisa y aprueba o solicita revisiones
  • El flujo vuelve al estado en progreso si se necesitan revisiones

Sistema de Valoraciones Bidireccional

Construye confianza mediante reseñas transparentes:

  • Valoraciones de 1-5 estrellas tras la finalización del servicio
  • Tanto clientes como proveedores se valoran mutuamente
  • Las valoraciones alimentan un algoritmo de confianza
  • Cálculo de valoración media con recuento total de reseñas
domain/model/User.java 
public void addValoracion(Double nota) {
    if (nota == null || nota < 0 || nota > 5)
        throw new IllegalArgumentException("Valoración inválida");
    this.puntuacionTotal += nota;
    this.numeroValoraciones++;
}

public Double getValoracionMedia() {
    if (numeroValoraciones == null || numeroValoraciones == 0)
        return 0.0;
    return Math.round((puntuacionTotal / numeroValoraciones) * 10.0) / 10.0;
}

Arquitectura de la Plataforma

iMirly está construido sobre una base de tecnologías modernas y escalables:

Frontend (Android)

  • Lenguaje: Kotlin
  • Framework UI: Jetpack Compose (UI 100% declarativa)
  • Navegación: Compose Navigation
  • Redes: Retrofit + OkHttp
  • Gestión de Estado: ViewModels y Coroutines
  • Autenticación: Interceptores de token JWT

Backend (Servidor API)

  • Núcleo: Java 21 + Spring Boot 4.0.3
  • Arquitectura: Arquitectura Hexagonal/Limpia
  • Persistencia: Spring Data JPA + Hibernate
  • Base de Datos: PostgreSQL 15
  • Seguridad: Spring Security con JWT y BCrypt
  • Datos de Prueba: Seeders automáticos

Nota: iMirly se encuentra actualmente en estado MVP. Funcionalidades como Stripe, WebSocket y mapas interactivos están planificadas.
