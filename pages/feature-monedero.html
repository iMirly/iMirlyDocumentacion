Monedero Virtual

Sistema de depósito seguro con gestión de saldo, historial de transacciones y seguimiento de ganancias pendientes

Descripción General

La billetera virtual iMirly ofrece un sistema de depósito seguro para gestionar los pagos entre clientes y proveedores de servicios. El dinero se guarda de forma segura durante la prestación del servicio y se libera solo tras la aprobación del trabajo, protegiendo así a ambas partes.

Flujo de Usuario

1

Añadir Fondos

Los clientes añaden dinero al saldo de su billetera para pagar los servicios (actualmente en incrementos de 10€).

2

Pagar por Servicios

Al aceptar un presupuesto, los fondos se deducen del saldo del cliente y se mantienen en depósito en garantía.

3

Finalización del Trabajo

Los proveedores completan el trabajo mientras el dinero se guarda de forma segura. Las ganancias se muestran como "Pendientes" en su billetera.

4

Liberar Fondos

Cuando el cliente aprueba el trabajo, los fondos se liberan del depósito en garantía al saldo disponible del proveedor.

5

Retirar

Los proveedores pueden retirar el saldo disponible a su cuenta bancaria.

Modelo de Vista de Billetera

Kotlin
SaldoViewModel.kt 
class SaldoViewModel : ViewModel() {
    var saldo = mutableStateOf(0.0)
    var pendiente = mutableStateOf(0.0)
    var esteMes = mutableStateOf(0.0)
    var transacciones = mutableStateOf>(emptyList())
    var isLoading = mutableStateOf(true)
    
    init {
        cargarDatos()
    }
    
    fun cargarDatos() {
        viewModelScope.launch {
            try {
                val response = RetrofitClient.userService.getWallet()
                if (response.isSuccessful) {
                    val data = response.body()
                    saldo.value = data?.saldo ?: 0.0
                    pendiente.value = data?.pendiente ?: 0.0
                    esteMes.value = data?.esteMes ?: 0.0
                    transacciones.value = data?.transacciones ?: emptyList()
                }
            } catch (e: Exception) {
                Log.e("SaldoViewModel", "Error loading wallet", e)
            } finally {
                isLoading.value = false
            }
        }
    }
    
    fun ingresarSaldo() {
        viewModelScope.launch {
            try {
                RetrofitClient.userService.ingresarSaldo()
                cargarDatos() // Reload to show new balance
            } catch (e: Exception) {
                Log.e("SaldoViewModel", "Error adding funds", e)
            }
        }
    }
    
    fun retirarSaldo() {
        viewModelScope.launch {
            try {
                RetrofitClient.userService.retirarSaldo()
                cargarDatos() // Reload to show new balance
            } catch (e: Exception) {
                Log.e("SaldoViewModel", "Error withdrawing funds", e)
            }
        }
    }
}

@Getter
@Setter
public class User {
    private UUID id;
    private String nombre;
    private String email;
    private Double saldo; // Virtual wallet balance
    
    public void restarSaldo(Double cantidad) {
        if (cantidad == null || cantidad <= 0) {
            throw new IllegalArgumentException(
                "La cantidad a restar debe ser mayor que cero."
            );
        }
        if (this.saldo == null) this.saldo = 0.0;
        this.saldo -= cantidad;
    }
    
    public void sumarSaldo(Double cantidad) {
        if (cantidad == null || cantidad <= 0) {
            throw new IllegalArgumentException(
                "La cantidad a sumar debe ser mayor que cero."
            );
        }
        if (this.saldo == null) this.saldo = 0.0;
        this.saldo += cantidad;
    }
}

Tipos de Transacciones

INGRESO

El cliente agrega fondos a la billetera

RETIRO

Usuario retira fondos al banco

SERVICIO_PAGADO

Cliente paga por el servicio (débito)

SERVICIO_COBRADO

Proveedor recibe pago (crédito)

WalletController.java 
@GetMapping("/wallet")
public ResponseEntity getWallet() {
    try {
        String tokenEmail = SecurityContextHolder.getContext()
            .getAuthentication().getName();
        User user = getUserUseCase.getUserByEmail(tokenEmail);
        
        // Calculate pending earnings from contracts in PAGADO state
        List solicitudes = 
            solicitudContratoUseCase.getSolicitudesPorProveedor(user.getId());
        
        Double pendiente = solicitudes.stream()
            .filter(s -> s.getEstado() == EstadoSolicitud.PAGADO ||
                        s.getEstado() == EstadoSolicitud.EN_CURSO ||
                        s.getEstado() == EstadoSolicitud.REVISION_PENDIENTE)
            .mapToDouble(SolicitudContrato::getPrecioAcordado)
            .sum();
        
        // Get transaction history
        List transacciones = transaccionRepository
            .findByUsuarioIdOrderByFechaDesc(user.getId());
        
        // Calculate this month's earnings
        Double esteMes = transacciones.stream()
            .filter(t -> t.getFecha().getMonth() == LocalDateTime.now().getMonth() &&
                        t.getFecha().getYear() == LocalDateTime.now().getYear())
            .filter(t -> t.getTipo().equals("INGRESO") || 
                        t.getTipo().equals("SERVICIO_COBRADO"))
            .mapToDouble(TransaccionEntity::getCantidad)
            .sum();
        
        // Format recent transactions (last 10)
        List recientes = transacciones.stream()
            .limit(10)
            .map(t -> {
                String amt = t.getTipo().equals("RETIRO") || 
                            t.getTipo().equals("SERVICIO_PAGADO")
                    ? "-" + String.format("%.2f€", t.getCantidad())
                    : "+" + String.format("%.2f€", t.getCantidad());
                return new TransaccionDTO(
                    t.getDescripcion(),
                    t.getTipo(),
                    amt,
                    "Completado",
                    t.getFecha().toLocalDate().toString()
                );
            })
            .collect(Collectors.toList());
        
        SaldoResponse resp = new SaldoResponse(
            user.getSaldo(), 
            pendiente, 
            esteMes, 
            recientes
        );
        return ResponseEntity.ok(resp);
    } catch (Exception e) {
        return ResponseEntity.badRequest().body(e.getMessage());
    }
}

Cálculo de Ganancias Pendientes: El backend suma todos los precios de los contratos donde el usuario es el proveedor y el contrato se encuentra en estado PAGADO, EN_CURSO o REVISIÓN_PENDIENTE. Esto representa el dinero retenido en depósito.

Flujo de Pago con Depósito en Garantía

1. Cliente Acepta Presupuesto

El cliente tiene saldo suficiente y acepta el presupuesto del proveedor

2. Fondos Retenidos en Escrow

El dinero se deduce del cliente y se mantiene seguro en depósito durante el servicio

3. Trabajo Completado y Aprobado

El proveedor finaliza el trabajo y el cliente aprueba la entrega

4. Liberación de Fondos

El dinero se transfiere al saldo disponible del proveedor para retiro

Cuando un Cliente Acepta un Presupuesto

Java
SolicitudContratoService.java 
@Transactional
public SolicitudContrato pagarSolicitud(UUID solicitudId, UUID clienteId) {
    SolicitudContrato solicitud = repositoryPort.findById(solicitudId)
        .orElseThrow();
    
    User cliente = userRepository.findById(clienteId)
        .orElseThrow();
    
    // 1. Deduct from client balance
    cliente.restarSaldo(solicitud.getPrecioAcordado());
    userRepository.save(cliente);
    
    // 2. Log transaction
    TransaccionEntity tr = new TransaccionEntity(
        null, cliente.getId(), 
        solicitud.getPrecioAcordado(), 
        "SERVICIO_PAGADO",
        "Pago de presupuesto en iMirly", 
        LocalDateTime.now()
    );
    transaccionRepository.save(tr);
    
    // 3. Move contract to PAGADO (escrow) state
    solicitud.pagarPresupuesto();
    return repositoryPort.save(solicitud);
}

Cuando el Trabajo Está Aprobado y Finalizado

Java
SolicitudContratoService.java 
public SolicitudContrato cambiarEstado(CambiarEstadoSolicitudCommand command) {
    SolicitudContrato solicitud = repositoryPort.findById(command.getSolicitudId())
        .orElseThrow();
    
    solicitud.setEstado(command.getNuevoEstado());
    
    // Release escrow to provider when completed
    if (command.getNuevoEstado() == EstadoSolicitud.COMPLETADO) {
        User proveedor = userRepository.findById(solicitud.getProveedorId())
            .orElseThrow();
        
        // Add to provider balance
        proveedor.sumarSaldo(solicitud.getPrecioAcordado());
        userRepository.save(proveedor);
        
        // Log transaction
        TransaccionEntity tr = new TransaccionEntity(
            null, proveedor.getId(), 
            solicitud.getPrecioAcordado(), 
            "SERVICIO_COBRADO",
            "Cobro por trabajo en iMirly", 
            LocalDateTime.now()
        );
        transaccionRepository.save(tr);
    }
    
    return repositoryPort.save(solicitud);
}

@Composable
fun TransactionListItem(
    title: String, 
    subtitle: String, 
    amount: String, 
    status: String, 
    time: String
) {
    val isPendiente = status.contains("Pendiente", ignoreCase = true)
    val isRetiro = amount.startsWith("-") || title.contains("Retiro", ignoreCase = true)
    
    val statusColor = if (isPendiente) Color(0xFFFFB800) else Color(0xFF2ECC71)
    val statusBgColor = if (isPendiente) Color(0xFFFFF7E6) else Color(0xFFE6F9F0)
    val amountColor = if (isRetiro) Color.Red else statusColor
    
    Row(
        modifier = Modifier.fillMaxWidth().padding(vertical = 12.dp),
        verticalAlignment = Alignment.CenterVertically
    ) {
        Column(modifier = Modifier.weight(1f)) {
            Text(title, fontWeight = FontWeight.SemiBold)
            Text(subtitle, color = Color.Gray, fontSize = 12.sp)
            Text(time, color = Color.LightGray, fontSize = 11.sp)
        }
        
        Column(horizontalAlignment = Alignment.End) {
            Text(amount, fontWeight = FontWeight.Bold, color = amountColor)
            Surface(
                shape = RoundedCornerShape(12.dp),
                color = statusBgColor
            ) {
                Text(
                    status, 
                    color = statusColor, 
                    fontSize = 9.sp,
                    modifier = Modifier.padding(horizontal = 8.dp, vertical = 2.dp)
                )
            }
        }
    }
}

Características de Seguridad

Validación de Saldo

Previene sobregiros y saldos negativos:

Java
User.java 
public void restarSaldo(Double cantidad) {
    if (cantidad == null || cantidad <= 0) {
        throw new IllegalArgumentException(
            "La cantidad a restar debe ser mayor que cero."
        );
    }
    if (this.saldo == null) this.saldo = 0.0;
    if (this.saldo < cantidad) {
        throw new IllegalStateException("Saldo insuficiente");
    }
    this.saldo -= cantidad;
}

Atomicidad de las Transacciones

Todas las operaciones de billetera utilizan @Transactional para garantizar la atomicidad:

  • Actualizaciones de saldo Y registros de transacciones, o ninguno
  • Previene inconsistencias en los datos
  • Revertir cualquier error
Protección Garantizada

El sistema de depósito en garantía protege tanto al cliente (asegurando que el trabajo se complete antes de pagar) como al proveedor (garantizando que el dinero está disponible antes de comenzar).
