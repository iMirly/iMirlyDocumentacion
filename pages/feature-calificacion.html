Sistema de Calificación

Calificaciones de estrellas posteriores al servicio con cálculo automático de puntuación de perfil y envío en el chat

Descripción General

Tras la finalización de un servicio, iMirly invita a los clientes a calificar su experiencia con un sistema de 1 a 5 estrellas. Las calificaciones se envían directamente en el chat y actualizan automáticamente la puntuación del perfil del proveedor, lo que genera confianza y responsabilidad en el mercado.

Flujo de Usuario

1

Finalización del Servicio

Una vez que el cliente aprueba el trabajo y se libera el pago, el contrato pasa al estado COMPLETADO.

2

Aparece el Mensaje de Calificación

La entrada del chat se reemplaza con una barra de calificación que solicita al cliente que deje una reseña.

3

Seleccione la Clasificación por Estrellas

El cliente toca las estrellas para seleccionar su calificación de 1 (mala) a 5 (excelente).

4

Enviar Calificación

El cliente pulsa "Enviar Valoración" y la calificación se envía como un tipo de mensaje especial.

5

Actualización de Perfil

El backend actualiza automáticamente la calificación promedio del proveedor y el recuento total de reseñas.

            }
        }

        // Chat messages...
    }
}

@Composable
fun ValoracionBar(
    viewModel: ChatViewModel, 
    otroUsuarioId: String, 
    solicitudId: String, 
    primaryColor: Color
) {
    var selectedStar by remember { mutableStateOf(0) }
    
    Surface(color = Color(0xFFFFF9E6), shadowElevation = 8.dp) {
        Column(
            modifier = Modifier.fillMaxWidth().padding(16.dp),
            horizontalAlignment = Alignment.CenterHorizontally
        ) {
            Text(
                "¡El servicio ha finalizado!", 
                fontWeight = FontWeight.Bold, 
                color = primaryColor
            )
            Text(
                "Valora tu experiencia de 1 a 5 estrellas.", 
                fontSize = 14.sp, 
                color = Color.DarkGray
            )
            
            Spacer(modifier = Modifier.height(12.dp))
            
            // Star rating selector
            Row(horizontalArrangement = Arrangement.Center) {
                for (i in 1..5) {
                    IconButton(onClick = { selectedStar = i }) {
                        if (i <= selectedStar) {
                            Icon(
                                Icons.Filled.Star, 
                                contentDescription = null,
                                tint = Color(0xFFFFB800),
                                modifier = Modifier.size(36.dp)
                            )
                        } else {
                            Icon(
                                Icons.Outlined.Star, 
                                contentDescription = null,
                                tint = Color.Gray,
                                modifier = Modifier.size(36.dp)
                            )
                        }
                    }
                }
            }
            
            // Submit button (only shown after selecting)
            if (selectedStar > 0) {
                Spacer(modifier = Modifier.height(8.dp))
                Button(
                    onClick = { 
                        viewModel.enviarValoracion(
                            otroUsuarioId, 
                            solicitudId, 
                            selectedStar.toDouble()
                        ) 
                    },
                    colors = ButtonDefaults.buttonColors(
                        containerColor = primaryColor
                    ),
                    modifier = Modifier.fillMaxWidth()
                ) {
                    Text("Enviar Valoración")
                }
            }
        }
    }
}

Enviando Calificación

Kotlin
ChatViewModel.kt 
fun enviarValoracion(
    receptorId: String, 
    solicitudId: String, 
    nota: Double
) {
    viewModelScope.launch {
        try {
            val requestMsg = EnviarMensajeRequest(
                receptorId = receptorId,
                contenido = "$nota|He dejado una valoración de $nota estrellas.",
                solicitudId = solicitudId,
                tipo = "VALORACION"
            )
            val msgResponse = RetrofitClient.mensajeService.enviarMensaje(requestMsg)
            if (msgResponse.isSuccessful) cargarConversacion(receptorId)
        } catch (e: Exception) {
            Log.e("ChatViewModel", "Error submitting rating", e)
        }
    }
}

Implementación Backend

Campos de Calificación del Usuario

Los usuarios rastrean sus datos de calificación acumulada:

Java
User.java 
@Getter
@Setter
public class User {
    private UUID id;
    private String nombre;
    private String email;
    private Double puntuacionTotal;
    private Integer numeroValoraciones;
    
    public void addValoracion(Double nota) {
        if (nota == null || nota < 0 || nota > 5)
            throw new IllegalArgumentException("Nota inválida");
        if (this.puntuacionTotal == null)
            this.puntuacionTotal = 0.0;
        if (this.numeroValoraciones == null)
            this.numeroValoraciones = 0;
        
        this.puntuacionTotal += nota;
        this.numeroValoraciones++;
    }
    
    public Double getValoracionMedia() {
        if (numeroValoraciones == null || numeroValoraciones == 0)
            return 0.0;
        return Math.round((puntuacionTotal / numeroValoraciones) * 10.0) / 10.0;
    }
}

La calificación promedio se calcula a pedido con precisión de 1 decimal (por ejemplo, 4,7) dividiendo los puntos totales por el número de reseñas.

Manejador de Calificación del Servicio de Mensajes

Cuando se envía un mensaje de calificación, el servicio actualiza el perfil del proveedor:

Java
MensajeService.java 
@Service
public class MensajeService implements MensajeUseCase {
    
    @Override
    @Transactional
    public Mensaje enviarMensaje(EnviarMensajeCommand command) {
        // ... other message type handling ...
        
        if (command.getTipo() == TipoMensaje.VALORACION) {
            User valorado = userRepositoryPort.findById(command.getReceptorId())
                .orElseThrow(() -> new IllegalArgumentException(
                    "Usuario a valorar no encontrado"
                ));
            
            try {
                // Parse "5.0|Rating text" format
                String[] partes = command.getContenido().split("\\|");
                Double nota = Double.parseDouble(partes[0].trim());
                
                // Update user's rating statistics
                valorado.addValoracion(nota);
                userRepositoryPort.save(valorado);
            } catch (Exception e) {
                throw new IllegalArgumentException(
                    "El formato de la valoración es incorrecto."
                );
            }
        }
        
        // Create and save the message
        Mensaje nuevoMensaje = new Mensaje(
            command.getRemitenteId(),
            command.getReceptorId(),
            command.getSolicitudId(),
            command.getContenido(),
            command.getTipo()
        );
        
        return repositoryPort.save(nuevoMensaje);
    }
}

public ResponseEntity getUserProfile(@PathVariable String email) {
    String tokenEmail = SecurityContextHolder.getContext()
        .getAuthentication().getName();
    
    if (!email.equals(tokenEmail)) {
        return ResponseEntity.status(403).body("Prohibido.");
    }

    UserProfileResponse response = new UserProfileResponse(
        user.getId(), 
        user.getNombre(), 
        user.getEmail(), 
        user.getDocumentoIdentidad(),
        user.getSaldo(), 
        user.getValoracionMedia(),      // e.g., 4.7
        user.getNumeroValoraciones()    // e.g., 23
    );
    return ResponseEntity.ok(response);
}

Validación de Calificación

Validación del Lado del Cliente

  • Solo se aceptan números enteros del 1 al 5 mediante selección de estrellas
  • El botón Enviar solo aparece después de seleccionar estrellas
  • La barra de calificación solo se muestra una vez por cada servicio completado

Estadísticas de Calificación

Método de Cálculo

La calificación promedio se calcula como:

Fórmula 
valoracionMedia = round(puntuacionTotal / numeroValoraciones * 10) / 10

Esto proporciona una precisión de 1 decimal (por ejemplo, 4,7 en lugar de 4,666667).

Ejemplo de Cálculo

5, 4, 5, 4, 5
Calificaciones recibidas
23.0
puntuacionTotal
5
numeroValoraciones
4.6
valoracionMedia

Cálculo: round(23.0 / 5 * 10) / 10 = round(4.6 * 10) / 10 = 46 / 10 = 4.6

Beneficios de Generar Confianza

Responsabilidad del Proveedor

Las calificaciones públicas motivan a los proveedores a ofrecer un trabajo de calidad y un servicio profesional.

Confianza del Cliente

Los clientes pueden revisar las calificaciones de los proveedores antes de solicitar servicios, lo que reduce el riesgo.

Sistema de Reputación

Las calificaciones acumulativas construyen la reputación del proveedor a lo largo del tiempo, recompensando la consistencia.

Filtro de Calidad

Las calificaciones altas ayudan a los mejores proveedores a destacarse en los resultados de búsqueda del mercado.

Visibilidad de la Calificación

Exhibición Pública

Las calificaciones son visibles en:

  • Las páginas de perfil del proveedor
  • Tarjetas de listado en servicio
  • En los resultados de búsqueda
  • En mensajes de servicio completados
4.7 (23 valoraciones)

Privacidad

Detalles de la calificación protegidos:

  • Calificaciones individuales que no se muestran públicamente
  • Solo se muestran el promedio agregado y el recuento
  • Mensajes de calificación visibles solo para los participantes de la conversación
