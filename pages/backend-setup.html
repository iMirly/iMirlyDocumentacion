Configuración del Backend

Pon en marcha el backend Spring Boot localmente

Prerrequisitos

Asegúrate de tener instalado lo siguiente:

Java 25

Requerido para Spring Boot 4.0.3

Versión 25

Maven 3.8+

Para gestión de dependencias

3.8 o superior

PostgreSQL 14+

Servidor de base de datos

14 o superior

Pasos de Instalación

  1. Instalar Java 25

    Descarga e instala Java 25 desde Oracle o usa SDKMAN:

    Terminal
    Instalar con SDKMAN 
    # Usando SDKMAN
sdk install java 25-open
sdk use java 25-open

# Verificar instalación
java -version

    Salida esperada:

    Salida 
    java version "25" 2025-XX-XX

  2. Instalar PostgreSQL

    Terminal
    macOS con Homebrew 
    # Usando Homebrew
brew install postgresql@14
brew services start postgresql@14

  3. Crear la Base de Datos

    Crea la base de datos iMirly y el usuario:

    Terminal
    PostgreSQL 
    # Acceder a PostgreSQL
psql -U postgres
    SQL
    Crear DB y Usuario 
    -- Crear base de datos
CREATE DATABASE imirly_db;

-- Crear usuario
CREATE USER user_imirly WITH PASSWORD 'password_imirly';

-- Otorgar privilegios
GRANT ALL PRIVILEGES ON DATABASE imirly_db TO user_imirly;

-- Salir de psql
\q
    Nota de Seguridad

    Estas credenciales coinciden con la configuración en application.properties. ¡Cámbialas en producción!

  4. Clonar y Navegar

    Terminal
    Git 
    # Clonar el repositorio (si no lo has hecho)
git clone 
cd source/backend

  5. Configurar Application Properties

    Revisa y actualiza src/main/resources/application.properties si es necesario:

    Properties
    application.properties 
    spring.application.name=iMirly
spring.datasource.url=jdbc:postgresql://localhost:5432/imirly_db
spring.datasource.username=user_imirly
spring.datasource.password=password_imirly
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
    Configuración de Producción

    spring.jpa.hibernate.ddl-auto=update actualiza automáticamente el esquema. ¡Usa validate en producción!

  6. Compilar el Proyecto

    Terminal
    Maven 
    # Limpiar y empaquetar
./mvnw clean package

# O en Windows
mvnw.cmd clean package

    Esto hará lo siguiente:

    • Descargar todas las dependencias de pom.xml
    • Compilar el código fuente Java
    • Ejecutar pruebas (si las hay)
    • Crear un archivo JAR en target/

  7. Ejecutar la Aplicación

    Terminal
    Ejecutar con Maven 
    ./mvnw spring-boot:run

    Deberías ver una salida como:

    Salida 
    Started IMirlyApplication in 3.456 seconds (process running for 4.123)

  8. Verificar que el Servidor está Corriendo

    La aplicación se ejecuta en el puerto 8080 por defecto. Prueba con:

    Terminal
    cURL 
    curl http://localhost:8080/api/v1/health

    O visita http://localhost:8080 en tu navegador para ver la aplicación en ejecución.

Estructura del Proyecto

backend/
├── pom.xml # Dependencias Maven
├── mvnw # Wrapper de Maven (Unix)
├── mvnw.cmd # Wrapper de Maven (Windows)
├── src/
│ ├── main/
│ │ ├── java/tfg/imirly/
│ │ │ ├── IMirlyApplication.java
│ │ │ ├── auth/ # Módulo de autenticación
│ │ │ └── catalog/ # Módulo de catálogo de servicios
│ │ └── resources/
│ │ └── application.properties
│ └── test/
│ └── java/ # Archivos de prueba
└── target/ # Salida compilada (generada)

Flujo de Desarrollo

Usando Maven Wrapper

El proyecto incluye wrappers de Maven (mvnw y mvnw.cmd) para que no necesites tener Maven instalado globalmente:

Terminal
Comandos Comunes de Maven 
# Limpiar compilación
./mvnw clean

# Compilar
./mvnw compile

# Ejecutar pruebas
./mvnw test

# Empaquetar JAR
./mvnw package

# Ejecutar aplicación
./mvnw spring-boot:run

Recarga en Caliente con Spring DevTools

Añade a pom.xml para reinicio automático al cambiar el código:

XML
pom.xml 
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-devtools</artifactId>
    <scope>runtime</scope>
    <optional>true</optional>
</dependency>

Configuración de Lombok

El proyecto usa Lombok para reducir código repetitivo. Configura tu IDE:

IntelliJ IDEA: Instala el plugin de Lombok desde el Marketplace, luego habilita el procesamiento de anotaciones: Archivo → Configuración → Compilación, Ejecución, Despliegue → Compilador → Procesadores de Anotaciones → Marcar "Habilitar procesamiento de anotaciones"

Creación del Esquema de Base de Datos

Con spring.jpa.hibernate.ddl-auto=update, Hibernate crea automáticamente las tablas basadas en clases @Entity:

Java
UserEntity.java 
@Entity
@Table(name = "usuarios")
public class UserEntity {
    @Id
    @GeneratedValue(strategy = GenerationType.UUID)
    private UUID id;
    
    private String nombre;
    private String email;
    
    @Column(name = "password_hash")
    private String passwordHash;
    // ... más campos
}

Esto crea automáticamente la tabla usuarios:

SQL
Esquema Generado 
CREATE TABLE usuarios (
    id UUID PRIMARY KEY,
    nombre VARCHAR(255),
    email VARCHAR(255),
    password_hash VARCHAR(255),
    tipo_usuario VARCHAR(50),
    documento_identidad VARCHAR(255),
    verificado BOOLEAN,
    fecha_registro TIMESTAMP,
    saldo DECIMAL(10,2) DEFAULT 0.0,
    puntuacion_total DOUBLE PRECISION DEFAULT 0.0,
    numero_valoraciones INTEGER DEFAULT 0
);

Problemas Comunes

Puerto 8080 ya en uso

Cambia el puerto en application.properties: server.port=8081 o mata el proceso que usa el puerto 8080.

Conexión PostgreSQL rechazada

Asegúrate de que PostgreSQL esté corriendo: brew services start postgresql@14 (macOS) o sudo service postgresql start (Linux).

Anotaciones de Lombok no funcionan

Habilita el procesamiento de anotaciones en tu IDE y asegúrate de que el plugin de Lombok esté instalado.

Error de validación de esquema

Establece spring.jpa.hibernate.ddl-auto=create-drop temporalmente para recrear el esquema, luego vuelve a update.

Variables de Entorno

Para producción, usa variables de entorno en lugar de codificar credenciales:

Properties
application.properties 
spring.datasource.url=${DB_URL:jdbc:postgresql://localhost:5432/imirly_db}
spring.datasource.username=${DB_USERNAME:user_imirly}
spring.datasource.password=${DB_PASSWORD:password_imirly}

Luego configúralas:

Terminal
Variables de Entorno 
export DB_URL=jdbc:postgresql://prod-server:5432/imirly_prod
export DB_USERNAME=prod_user
export DB_PASSWORD=strong_password
